# Architecture decisions

ADR-001: Local-first SQLite default; optional PostgreSQL later.

ADR-002: Primary provider consumes weekly subscription usage, not Platform API key or purchased credits; fail closed on quota.

ADR-003: Browser STT/TTS early; never equate recognition output with acoustic accuracy.

ADR-004: Modular monolith planned, not premature microservices.

ADR-005: Initial commit is scaffold only; capabilities verified before claims.
